Web

L'application web, sur ordinateur, tablette et smartphone (Android et iPhone)

L’application web est disponible sur app.vigilo.city, depuis n’importe quel navigateur récent.

  • Ajoutez une observation depuis une photo prise sur place, choisie dans votre galerie ou collée (Ctrl+V) sur ordinateur
  • Consultez les observations en liste ou sur la carte, avec leurs photos et les observations à proximité
  • Installez-la sur votre écran d’accueil (Android, iPhone, ordinateur) pour l’ouvrir comme une application
  • Mode modérateur pour les associations
